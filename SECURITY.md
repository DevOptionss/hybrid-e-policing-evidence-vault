# Security notes

This repository is a **research prototype** from an Honours project. It is not hardened and it must not be used to store real evidence.

## What to know before running it

- **The chaos map ciphers have not had formal cryptanalysis.** The default ("perturbed") cipher and the original ("basic") cipher passed the statistical tests in `vault/tests/cipher-evaluation.js`, but a statistical pass is not a security proof. The original cipher repeats completely when one seed is used for a stream longer than about 14 MiB (see `docs/RESULTS.md`). Integrity in this project rests on SHA-256 and the Merkle tree, not on the cipher.
- **Test keys are fixed.** The test scripts use the key `0.3141592653589793`. Real use would need proper key generation, storage and recovery.
- **The Fabric network is the standard test network.** Its identities are generated by a development tool, it runs on one machine, and it has no certificate authority.
- **Demo mode is not a blockchain.** `node server.js --demo` runs the real chaincode logic against an in memory store that is lost when the server stops.
- **The server trusts its caller.** The HTTP interface has no login. It binds to `127.0.0.1` only. Do not expose it on a network.
- **The ingest by path endpoint reads files from the server's disk.** That is acceptable for a local demonstration and unsafe on a shared machine.

## Never commit

Certificates, private keys, the Fabric `organizations` folder, `vault_meta.json` and real case material. The `.gitignore` excludes the usual paths, but check `git status` before every push.

## Reporting a problem

Please open an issue on the repository. For anything sensitive, contact the author through the university address listed on the profile of the repository owner.
